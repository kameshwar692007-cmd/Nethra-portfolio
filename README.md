## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation
```bash
git clone https://github.com/kameshwar692007-cmd/Nethra-portfolio.git
cd Nethra-portfolio
npm install
```

### Development Server
```bash
npm run dev
```

### Production Build
```bash
npm run build
```
